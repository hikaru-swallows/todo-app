# やることリストアプリ
HTML・CSS・JavaScriptで作成したToDoアプリです。

## アプリ概要
タスクの追加・編集・削除ができるアプリです。 LocalStorageを利用し、ブラウザを再読み込みしてもデータが保持されるようにしています。

## 実装機能
- タスク追加
- タスク編集
- タスク削除
- 完了状態切替
- 日時設定
- フィルター機能
- LocalStorage保存

## 使用技術
- HTML
- CSS
- JavaScript

## 工夫した点
- タスクに日時を設定できるようにした
- 完了・未完了でフィルターできるようにした
- LocalStorageを利用しデータを保持できるようにした
- 緑を基調とした見やすいデザインを意識した
